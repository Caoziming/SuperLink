# Super Link（浏览器扩展）

**功能强大的书签工具 · 一站式管理你的书签。** 链接与分组在 `data.js` 中定义初始数据，支持右键编辑 / 删除（自动持久化）、标签分组导航、关键字模糊搜索、浏览器书签导入与同步管理、深浅色模式、多列布局、账号密码一键复制等。

基于 Chromium 的 Manifest V3 标准开发，可在 **Chrome、Edge** 及其他常见 Chromium 内核浏览器（Brave、Opera、360 极速浏览器、QQ 浏览器等）中直接安装使用，无需任何代码改动。

## 2. 目录结构

```
SuperLink/
├── manifest.json    # 扩展配置（Manifest V3）
├── popup.html       # 弹窗页面结构
├── popup.css        # 弹窗样式（深浅色主题）
├── popup.js         # 渲染 / 标签切换 / 搜索 / 复制 / 跳转 / 浏览器书签读取逻辑
├── background.js    # Service Worker（工具栏图标右键菜单：在侧边栏打开）
├── data.js          # ★ 链接数据（分类 + 颜色 + 链接，全在这里维护）
├── help.html        # 帮助说明页（功能使用说明，新标签页打开）
├── sidepanel.html   # 侧边栏模式页面（与 popup.html 同构，共用 popup.js/css）
└── icons/           # 扩展图标（16 / 48 / 128）
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 3. 浏览器安装与使用

### 3.1 浏览器兼容性

| 浏览器       | 是否可用 | 安装入口（地址栏输入）                      |
| --------- | ---- | -------------------------------- |
| Chrome    | ✅    | `chrome://extensions/`           |
| Edge      | ✅    | `edge://extensions/`             |
| Brave     | ✅    | `brave://extensions/`            |
| Opera     | ✅    | `opera://extensions/`            |
| 360 极速浏览器 | ✅    | `se://extensions/`（或菜单 → 扩展管理）   |
| QQ 浏览器    | ✅    | `qqbrowser://extensions/`（或应用中心） |
| Firefox   | ❌    | 未适配（不兼容 Chromium 扩展体系）           |

各浏览器的安装流程完全一致，只有「扩展管理页地址」和按钮名称略有差异，下面以 Chrome 和 Edge 为例。

### 3.2 Chrome 安装步骤

1. 地址栏输入并访问：`chrome://extensions/`
2. 打开页面右上角的 **「开发者模式」** 开关
3. 点击左上角 **「加载已解压的扩展程序」** 按钮
4. 在弹出的文件夹选择框中，选中 **`SuperLink`** 文件夹（即包含 `manifest.json` 的目录）
5. 扩展列表中出现「Super Link」，安装成功

### 3.3 Edge 安装步骤

1. 地址栏输入并访问：`edge://extensions/`
2. 打开页面左侧的 **「开发人员模式」** 开关（Edge 叫"开发人员模式"，位置在左侧边栏）
3. 点击页面上方的 **「加载解压缩的扩展」** 按钮
4. 选择 **`SuperLink`** 文件夹，完成安装

### 3.4 其他 Chromium 内核浏览器（Brave / Opera / 360 极速 / QQ 浏览器）

流程与 Chrome 相同：

1. 地址栏输入 3.1 表格中对应的扩展管理地址（如 `brave://extensions/`）
2. 开启 **开发者模式** 开关
3. 点击 **加载已解压的扩展程序**（部分浏览器叫「加载扩展」/「开发者模式加载」）
4. 选择 **`SuperLink`** 文件夹即可

> 提示：国产浏览器（360 / QQ）若找不到入口，可尝试在扩展管理页右键或通过设置菜单查找「开发者模式」相关选项。

### 3.5 主题色自定义（各浏览器通用）

1. 点击头部右侧的 **调色板图标按钮**，弹出主题色面板
2. 选择方式：

   * 点击任一 **预置色块**（静谧蓝 / 梦幻紫 / 翡翠绿 / 青碧色 / 活力橙 / 玫瑰粉 / 石榴红 / 石墨灰）

   * 或点击「自定义」旁的 **取色器**，选择任意颜色，拖动时实时预览
3. 主题色会即时应用到链接文字、「全部」标签、搜索框聚焦光晕、卡片悬停阴影、账号已复制状态等处
4. 选择自动通过 localStorage 记忆，下次打开扩展保持上次主题；点「恢复默认」回到静谧蓝（#3370ff）
5. 点击面板外任意位置可关闭面板

> 分组标签与分组标题条的彩色圆点为项目边界标识色，不随主题色变化；Logo、标题文字与置顶按钮的彩虹渐变为品牌元素，同样保持不变。

### 3.6 日常使用（各浏览器通用）

1. 点击浏览器工具栏中的扩展图标（彩色描边书签图标（透明底））；若图标未显示，点击工具栏拼图图标 🧩 / Edge 的扩展图标，将「Super Link」固定（📌）到工具栏
2. 点击顶部 **标签** 切换项目边界，或直接在搜索框输入关键字筛选
3. 点击条目：

   * 普通条目 → 新标签页打开对应系统

   * 微信 H5 条目 → 复制链接，提示「链接已复制，请在微信中打开」

   * 点击条目右上角 **copy 图标** → 复制链接，底部弹出「✓ 复制成功」（所有条目可用）
4. 点击条目内的 **账号 / 密码 chip** 一键复制（注意：点击 chip 不会触发跳转）
5. 点击头部 **🔖 书签开关** 可显示 / 隐藏浏览器书签分组（详见第 5 节）
6. 标签较多换行时，点击标签栏右侧 **「展开 / 收起」** 按钮可折叠为一行或展开为多行（状态自动记忆）
7. 点击头部 **❓ 帮助按钮** 在新标签页打开功能使用说明（help.html）
8. 点击头部 **🕘 时钟按钮** 在新标签页打开浏览器历史记录页（Chrome 用 `chrome://history/`，Edge 用 `edge://history/`）
9. 点击头部 **侧边栏图标** 可切换为侧边栏常驻模式（详见 3.8）

### 3.7 更新扩展（修改数据后生效）

1. 修改 `data.js`（见第 4 节）并保存
2. 打开当前浏览器的扩展管理页（地址见 3.1 表格）
3. 找到「Super Link」卡片，点击刷新按钮 **↻**
4. 重新打开扩展弹窗，即可看到最新数据

> 多个浏览器同时安装时，共用同一份 `SuperLink` 文件夹，改一处数据，各浏览器分别点刷新 ↻ 即可全部生效。

### 3.8 启动模式（侧边栏 / 弹窗）

1. 点击头部 **调色板按钮**，在面板的 **「启动模式」** 中选择点击工具栏图标时的打开方式（需 Chrome/Edge 116+）：
   * **侧边栏**（默认）：点击工具栏图标直接以侧边栏常驻打开
   * **弹窗**：点击工具栏图标打开弹窗
2. 设置保存后立即生效（后台 Service Worker 自动调用 `setPanelBehavior` / `setPopup` 重新应用），浏览器重启后按配置固定打开；也可**右键工具栏扩展图标**选择「在侧边栏打开 Super Link」手动打开
3. 侧边栏不会像弹窗一样点击别处就关闭，适合一边工作一边保持打开；点击链接后在新标签页打开，侧边栏继续保持；标签折叠、书签开关、主题色等设置与弹窗模式互通

## 4. 如何增加 / 维护链接

### 4.1 维护入口

所有分类与链接数据集中维护在 **`data.js`** 文件中（分组名、分组颜色、链接条目均在此定义），修改后按 3.7 节刷新扩展即可生效，无需重新安装。

### 4.2 数据结构说明

```js
// 「全部」标签配置（名称 + 颜色）
const ALL_TAB = { name: '全部', color: '#6a8dff' };

const LINK_GROUPS = [
  {
    group: '常用工具',              // 分类名（即标签名，同时作为搜索匹配字段）
    color: '#6a8dff',               // 分类颜色（标签彩点 + 分组标题条，不配置则回退默认蓝）
    items: [
      {
        name: '示例站点',            // 条目名称（必填）
        platform: 'pc',             // 平台：'pc' PC端 | 'wechat' 微信H5 | null 不显示（可选）
        url: 'https://example.com/', // 链接地址（必填）
        note: '备注信息',            // 特殊提示，橙色提示条展示（可选）
        accounts: [                // 账号密码列表，没有则留空数组 []
          { label: '账户', username: 'user', password: 'pass' }
        ]
      }
    ]
  }
];
```

### 4.3 字段与行为对照

| 字段         | 取值              | 交互行为                                         |
| ---------- | --------------- | -------------------------------------------- |
| `platform` | `'pc'` 或 `null` | 点击条目 → **新标签页打开**                            |
| `platform` | `'wechat'`      | 点击条目 → **仅复制链接**（左侧绿色竖条标识，也可用右上角 copy 图标复制）              |
| `accounts` | 空数组 `[]`        | 不渲染账号密码行                                     |
| `accounts` | 有内容             | 渲染账号 chip（明文）+ 密码 chip（•••••• 遮罩），点击分别复制     |

### 4.4 常见维护场景

**新增一条链接**：在对应 `group` 的 `items` 数组中追加一个对象（参照 4.2 结构）。

**新增一个项目分组**：在 `LINK_GROUPS` 数组末尾追加一个 `{ group: '新分组名', color: '#ff9d2e', items: [...] }`，标签与分组标题颜色取自 `color` 字段，无需改动 `popup.js`：

```js
{
  group: '新分组名',
  color: '#ff9d2e',
  items: [ /* 链接条目 */ ]
}
```

**修改 / 删除链接**：直接编辑或删除对应的条目对象即可。

## 5. 浏览器书签集成

1. 点击头部 **🔖 书签开关**：开启后扩展读取浏览器书签（需要 `bookmarks` 权限），书签分组追加在内置标签之后；再次点击关闭
2. **文件夹 → 标签**：书签栏 / 其他书签下的每个文件夹都作为一个新标签，文件夹里的书签即为该标签下的条目
3. 嵌套文件夹以「父文件夹/子文件夹」路径命名（如 `工作/后台`），因此不会与内置分组重名冲突；空文件夹自动忽略
4. 书签条目点击后在新标签页打开，同样支持关键字搜索，并计入「全部」标签
5. 书签分组标题带 🔖 图标与内置分组区分，颜色按分组名自动分配（稳定不变）
6. 开关状态通过 localStorage 记忆，下次打开扩展保持

> 首次更新到带书签功能的版本后，需在扩展管理页点刷新 ↻ 重新加载，浏览器可能提示新增「读取书签」权限。

***

## 6. 其他说明

1. 新增分组若未配置 `color` 字段，标签与分组标题会自动回退到默认蓝色，不影响功能
2. 密码 chip 明文查看：鼠标悬停在 •••••• 上，通过 title 提示显示
3. 搜索快捷键：输入状态下按 `Esc` 快速清空搜索框
4. Firefox 暂不支持：本扩展基于 Chromium 的 Manifest V3 与 `chrome.*` API，未做 Firefox 适配
