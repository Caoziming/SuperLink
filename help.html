Super Link · 使用帮助

本文档说明扩展各功能怎么使用

目录
标签导航 标签折叠 搜索 打开链接 账号密码复制 环境与平台徽章 浏览器书签 主题色 置顶 侧边栏模式

1标签导航

顶部标签按项目边界划分，点击任一标签，列表只显示该标签下的链接；点击「全部」恢复展示全部链接。

标签上的数字表示该标签下的链接数量。

2标签折叠

标签较多换行时，标签栏右侧会出现「展开 / 收起」按钮：

· 折叠：标签栏只显示一行，放不下的标签暂时隐藏

· 展开：标签栏显示全部行数

折叠 / 展开状态会自动记忆，下次打开扩展保持上次的状态。

标签总数只有一行时，不会显示该按钮。

3搜索

在搜索框输入关键字，按名称 / URL / 备注 / 分组名 / 账号密码模糊筛选，不区分大小写。

多个关键字用空格分隔，表示「同时满足」（AND 查询）。例如输入 git 正式，查找名称或 URL 含「git」且属于正式环境（env 为 prod）的链接。

按 Esc 或点击输入框右侧的 × 快速清空搜索，恢复标签浏览。

4打开链接与复制链接

复制链接：每个条目右上角都有复制图标按钮，点击即复制该条目链接，底部弹出「✓ 复制成功」提示，不限于微信 H5 条目。

普通条目（PC 后台等）：点击卡片任意位置，在新标签页打开对应系统。

微信 H5 条目（卡片左侧有绿色竖条标识）：点击卡片同样只复制链接（与复制按钮效果一致），把链接粘贴到微信环境里打开即可。

5账号密码复制

带账号信息的条目下方会显示账户行：

· 点击账号 chip（明文显示）→ 复制账号

· 点击密码 chip（显示为 ••••••）→ 复制密码

鼠标悬停在密码 chip 上可以直接看到明文密码；点击 chip 不会触发跳转。

6环境与平台徽章

条目名称右侧的彩色小徽章：

· 橙色「测试」 = 测试环境链接；绿色「正式」 = 正式环境链接

· 「PC」 = 电脑端打开；「微信H5」 = 需在微信环境打开

7浏览器书签

点击头部 🔖 书签开关，可以把浏览器的书签加进列表：

· 每个书签文件夹作为一个标签，追加在内置标签之后；文件夹里的书签就是该标签下的条目

· 嵌套文件夹以「父文件夹/子文件夹」路径命名（如 工作/后台），空文件夹自动忽略

· 书签分组标题带 🔖 图标，与内置分组区分；点击书签条目直接在新标签页打开

开关状态会自动记忆；再次点击开关即可隐藏书签分组。

8主题色

点击头部调色板按钮，在弹出面板中选择：

· 8 种预置色块任选，或用「自定义」取色器选任意颜色（拖动实时预览）

· 点「恢复默认」回到静谧蓝

主题色会应用到链接文字、标签、搜索框光晕、卡片悬停阴影等处，并自动记忆；点击面板外任意位置关闭面板。

9置顶

列表下滑一段距离后，底部会出现彩色渐变的「置顶」按钮，点击后平滑回到列表顶部。

本帮助页由头部 ❓ 按钮打开；头部 🕘 时钟按钮可在新标签页打开浏览器历史记录；链接数据的增删改在扩展目录的 data.js 中维护。

10侧边栏模式

两种方式把 Super Link 以侧边栏常驻方式打开：

· 点击弹窗头部侧边栏图标按钮

· 右键工具栏扩展图标，选择「在侧边栏打开 Super Link」

侧边栏不会像弹窗一样点击别处就关闭，可以一边工作一边保持打开；点击链接后在新标签页打开，侧边栏继续保持；标签折叠、书签开关、主题色等设置与弹窗模式互通。

在侧边栏中点击头部「变为弹窗」图标按钮可切回弹窗模式；浏览器暂不支持自动关闭侧边栏，切换后侧边栏需手动收起。

工具栏图标点击仍是弹窗模式，两种模式并存、随时切换；侧边栏功能需要 Chrome 116 及以上版本，「变为弹窗」需要 Chrome 127 及以上。
