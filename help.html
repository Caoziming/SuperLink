Super Link · 使用帮助

本文档说明扩展各功能怎么使用

1标签导航

顶部标签按分组划分，点击任一标签，列表只显示该分组下的链接；点击「全部」恢复展示全部链接。标签上的数字表示链接数量。

点击分组标题可展开 / 收起该分组（箭头随状态旋转，收起状态自动记忆）；内容区顶部的双箭头小按钮可一键折叠 / 展开全部分组。

开启分组图标（头部标签形开关按钮）后，标签与分组标题显示类型图标——「全部」带书签图标、浏览器书签分组带 📁 文件夹图标、内置分组带 🔗 链环图标；关闭后恢复彩色圆点。

2标签折叠

标签较多换行时，标签栏右侧会出现「展开 / 收起」按钮：

· 收起：标签栏平滑收到一行，按钮上显示被隐藏的标签数（如「展开 +3」）

· 展开：平滑展开全部行数

折叠 / 展开状态会自动记忆，下次打开扩展保持上次的状态。

标签总数只有一行时，不会显示该按钮。

3搜索

在搜索框输入关键字，按名称 / URL / 备注 / 分组名 / 账号密码模糊筛选，不区分大小写。

多个关键字用空格分隔，表示「同时满足」（AND 查询）。例如输入 git 仓库，查找名称或 URL 同时含「git」和「仓库」的链接。

按 Esc 或点击输入框右侧的 × 快速清空搜索，恢复标签浏览。

搜索时标签栏会同步只显示有匹配链接的分组。

4打开链接与复制链接

复制链接：每个条目右上角都有复制图标按钮，点击即复制该条目链接，底部弹出「✓ 复制成功」提示，不限于微信 H5 条目。

普通条目（PC 后台等）：点击卡片任意位置，在新标签页打开对应系统。

微信 H5 条目（卡片左侧有绿色竖条标识）：点击卡片同样只复制链接（与复制按钮效果一致），把链接粘贴到微信环境里打开即可。

右键卡片可编辑链接名称 / 网址，或删除（删除需二次确认）；编辑后自动保存，浏览器书签条目的改动会同步写回浏览器书签。

右键分组标题可重命名分组，或在该分组下新增链接；浏览器书签文件夹的重命名 / 新增会直接写回浏览器书签。

链接名称最多显示 20 字，超出以省略号（…）截断；悬停名称可查看完整内容。名称前的小图标为该站点的 favicon（读取浏览器缓存，无外部请求）。

拖动卡片可调整链接顺序，或把链接拖到其他分组（出现蓝色指示线的位置即插入位置）；浏览器书签条目的移动会同步写回书签。

5账号密码复制

带账号信息的条目下方会显示账户行：

· 点击账号 chip（明文显示）→ 复制账号

· 点击密码 chip（显示为 ••••••）→ 复制密码

鼠标悬停在密码 chip 上可以直接看到明文密码；点击 chip 不会触发跳转。

6平台徽章

条目名称右侧的彩色小徽章：

· 「PC」 = 电脑端打开；「微信H5」 = 需在微信环境打开

7浏览器书签

点击头部 🔖 书签开关，可以把浏览器的书签加进列表：

· 每个书签文件夹作为一个标签，追加在内置标签之后；文件夹里的书签就是该标签下的条目

· 嵌套文件夹以「父文件夹/子文件夹」路径命名（如 工作/后台），空文件夹自动忽略

· 书签分组标题带 📁 文件夹图标，与内置分组区分；点击书签条目直接在新标签页打开

开关状态会自动记忆；再次点击开关即可隐藏书签分组。

书签导入 / 导出（浏览器操作）：书签数据保存在浏览器中，可随时备份或迁移到其他电脑：

· Chrome 导出：打开书签管理器（地址栏输入 chrome://bookmarks/，或按 Ctrl + Shift + O）→ 右上角 ⋮ 菜单 → 导出书签，浏览器会下载一个包含全部书签与文件夹结构的 HTML 备份文件

· Chrome 导入：书签管理器 → 右上角 ⋮ 菜单 → 导入书签，选择之前导出的 HTML 备份文件即可恢复（也支持从其他浏览器直接导入）

· Edge：地址栏输入 edge://favorites/（或按 Ctrl + Shift + O）打开收藏夹页，在页面菜单中选择导出收藏夹 / 导入收藏夹，操作方式相同

导出的 HTML 是各浏览器通用格式，Chrome / Edge / Firefox 可互相导入；导入完成后重新打开 Super Link 面板，新书签即会出现在书签分组中。

8主题色与显示模式

点击头部调色板按钮，面板内可设置：

· 主题色：8 种预置色块任选，或用「自定义」取色器选任意颜色（拖动实时预览），点「恢复默认」回到静谧蓝

· 显示模式：跟随系统（默认，系统切换深浅色时实时跟随）/ 白天 / 夜晚 三选一

主题色会应用到链接文字、标签、搜索框光晕、卡片悬停阴影等处；两项设置均自动记忆，点击面板外任意位置关闭面板。

9布局设置（侧边栏 / 独立窗口）

点击头部布局按钮（三栏网格图标），面板内可设置：

· 分类布局：上下（标签栏在内容上方，默认）或 左右（分类列在左、内容在右，两区各自独立滚动）

· 列表列数：单列至最多 8 列；多列时每列内部与单列一样行行紧贴，分组标题独占整行

左右布局下可拖拽中间分隔线调整分类区宽度（最小 110px），双击分隔线恢复默认宽度。

全部布局设置自动记忆；弹窗模式为固定单列布局。

10置顶与置底

列表下滑一段距离后，底部出现彩色渐变胶囊，左右两半：「置顶」平滑回到列表顶部，「置底」平滑到达列表底部；左右布局下胶囊居中于内容区底部。

本帮助页由头部 ❓ 按钮打开；头部 🕘 时钟按钮可在新标签页打开浏览器历史记录。链接的增删改通过右键菜单完成并自动保存，data.js 仅作为初始数据模板。

11启动模式（侧边栏 / 弹窗 / 独立窗口）

点击头部调色板按钮，在面板的「启动模式」里选择点击工具栏图标时的打开方式：

· 侧边栏（默认）：点击工具栏图标直接以侧边栏常驻打开

· 弹窗：点击工具栏图标打开弹窗

· 独立窗口：点击工具栏图标打开自由浮窗（默认 800px 宽，自动记住上次窗口尺寸）

设置保存后立即生效，浏览器重启后按配置固定打开；也可随时右键工具栏扩展图标，选择「在侧边栏打开 Super Link」手动打开侧边栏。

侧边栏不会像弹窗一样点击别处就关闭，适合一边工作一边保持打开；侧边栏功能需要 Chrome/Edge 116 及以上版本。
